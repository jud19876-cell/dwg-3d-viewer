========================================================================
   DWG / DXF 3D 웹 도면 뷰어 & 오토캐드 고화질 플롯 (배포용 버전 v1.0)
========================================================================

■ 시스템 개요
 본 프로그램은 대용량 오토캐드 2D/3D 도면(.dwg, .dxf)을 웹 브라우저에서 
 고속 렌더링하고, 원하는 도면 1장의 영역을 지정하여 A4/A3/A2 300 DPI 
 초고화질 흑백(monochrome.ctb) 및 컬러 PDF/PNG/프린터 출력을 제공하는 
 배포용 통합 도면 시스템입니다.

------------------------------------------------------------------------
■ [방법 1] 내 컴퓨터에서 1초 만에 바로 실행하기 (가장 쉬운 방법)
------------------------------------------------------------------------
 1) "DWG_3D_뷰어_실행.bat" 파일만 더블 클릭합니다.
 2) 검은색 콘솔 창이 뜨면서 브라우저(http://localhost:3000)가 자동으로 열립니다.
 3) 화면에 .dwg 또는 .dxf 도면 파일을 드래그 앤 드롭하면 즉시 도면이 열립니다!

------------------------------------------------------------------------
■ [방법 2] 사내 다른 사람들과 공유하여 함께 사용하기 (LAN 네트워크 공유)
------------------------------------------------------------------------
 1) 한 사람이 서버 컴퓨터에서 "DWG_3D_뷰어_실행.bat"을 켜둡니다.
 2) 서버 콘솔 창에 표시되는 [사내 사설망(LAN) 다른 사람 접속 주소]를 확인합니다.
    예: http://192.168.0.15:3000
 3) 같은 사무실/네트워크 안의 모든 직원은 각자의 컴퓨터 브라우저 주소창에
    위 주소를 입력하기만 하면 프로그램 설치 없이 누구나 똑같이 도면을 보고
    PDF 인쇄 출력을 이용할 수 있습니다!

------------------------------------------------------------------------
■ 주요 기능 및 조작법
------------------------------------------------------------------------
 1. 2D / 3D 자유 입체 시점 전환:
    - [2D/3D 전환] 버튼으로 3D 입체 투시도 및 2D 직교 평면도 즉시 전환
    - 마우스 왼쪽 드래그: 도면 이동 (Pan)
    - 마우스 휠: 확대 / 축소 (Zoom)
    - 마우스 오른쪽 드래그: 3D 회전 (Rotate)

 2. 오토캐드 고화질 플롯 / 인쇄 모드:
    - 상단 [🖨️ 도면 인쇄/출력] 버튼 클릭
    - [윈도우(O)<] 버튼 클릭 후 인쇄할 도면 1장의 네모 상자 영역 드래그 지정
    - [🔍 전체 화면 미리보기(P)...] 버튼으로 실제 A3 종이에 인쇄될 300 DPI 상태 미리 확인
    - [PDF 저장] / [PNG 저장] / [프린터 직접 인쇄] 지원 (monochrome.ctb 흑백 지원)

 3. 레이어 제어:
    - 상단 [레이어 목록] 버튼으로 개별 층/설비 레이어 On/Off 토글 지원

------------------------------------------------------------------------
